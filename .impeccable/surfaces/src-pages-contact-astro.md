# Surface Brief: Contact & Project Initiation

## Scope & Mode
- **Scope**: Contact Page (`src/pages/contact.astro`) & Interactive 3D Canvas / CTA System
- **Mode**: Persuade & Experience (Credibility proof, interactive project scoping, conversion)

## Direction contract

### THESIS
Refuses the static, dormant contact form with disabled placeholder buttons and crude 2D canvas diagrams. Owns an energetic, tactile 3D project observatory where technical precision (Three.js WebGL icosahedron, orbiting phase nodes) directly drives project scoping and conversion, bridging creative vision and engineering rigor.

### OWN-WORLD
Deep spatial obsidian background (`#0a0a0a`, `#0d0d0d`), vibrant brand crimson highlights (`#c70039`, `#e84c5f`), translucent frosted panels (`rgba(255,255,255,0.04)` with fine `border-white/10`), crisp typography (Poppins display, Raleway body), glowing telemetry pills, and dynamic WebGL point-and-wireframe shaders with reactive mouse gyroscope.

### STORY
The visitor explores Steve Moya's 5-stage collaboration lifecycle through an interactive 3D core. Clicking or hovering phase nodes (Brief, UX/UI, Full-Stack, SEO, Deploy) illuminates the project scope, reveals concrete deliverables, and automatically synchronizes with the project scope selectors in the contact form. The visitor can immediately send a structured inquiry or copy/share via WhatsApp, receiving instant feedback.

### FIRST VIEWPORT
Split 2-column desktop composition (stacked on mobile). Sticky left column hosts the 3D WebGL viewport with live interactive controls, phase status badge, and project scope chips. Right column hosts the real-time synchronized contact form with tactile inputs, active CTA with micro-animations, copy fallback, and social channels.

### FORM
Interactive 3D Geodesic Core with Orbiting Stage Constellation and Bidirectional Form Synchronization (1st choice among architectural concepts).
